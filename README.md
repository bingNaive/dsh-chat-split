# dsh-chat-split

让 DeepSeek Harness 在同一个窗口里并排聊天。

## 功能

- **新会话自动分屏**：点击原来的「新会话」，直接增加一个聊天分屏。
- **历史会话拖入分屏**：把侧栏中的历史对话向右拖入聊天区。
- **左右分屏预览**：拖到左边，左半边亮起；拖到右边，右半边亮起。松开后放到对应位置。
- **顶部布局选择**：拖到聊天区顶部，展开类似 Windows 的布局条。提供双栏、左宽右窄、左窄右宽、三栏、一主两副和四宫格，拖到小格后松开即可。
- **最多四个独立聊天**：各自输入、选择模型和保留草稿。选定布局中的空格，会在新建会话时依次填入。
- **随时恢复单窗**：移入分屏，点击右上角 □ 恢复单个对话，点击 × 关闭这一格。移出分屏的对话仍在历史列表中。

## 使用

从 [发布页](https://github.com/bingNaive/dsh-chat-split/releases) 下载 `.tgz` 安装包，不用解压。在 Harness 中打开「插件 → 添加插件 → 安装第三方插件」，填入文件完整路径，安装后点击「立即启用」。

打开一个对话后，点击「新会话」或拖入历史对话开始分屏。拖拽时按 Esc 可取消；选择格数更少的布局时，保留最近的对话。布局在刷新或重启后恢复单窗。

适用于 **DeepSeek Harness 0.2.1-rc.2**。
